## Pricing Model (Simplified)

**Fee Model:**
- Fee is collected at credit **purchase** (POS), not per-call
- User buys $100 credits → pays $105.50 (5.5% fee)
- Fee is immediately considered earned revenue
- Credits are deducted 1:1 against our provider cost

**Credit Deduction:**
- User's credits decrease by exactly what we pay the provider
- No margin tracking per API call
- Simpler accounting

## CI/CD Lesson

- Manual docker cp creates uncommitted local changes on server
- This breaks CI/CD git pull (conflicts)
- Always use: commit → push → let CI/CD deploy
- If stuck: `git stash` → `git pull` → rebuild
