## Lipaira API Operatorure Clarified

**Key decision:** All LLM traffic routes through our server (api.lipaira.ai):
- Local OS → encrypts → api.lipaira.ai → decrypts → LLM provider → encrypts → Local OS
- Users never see/input LLM API keys - we control the pipes
- 5.5% fee on credit purchases (NOT on LLM calls - handled at transaction point)
- Closed source system - no SDK

**Endpoint:** `POST https://api.lipaira.ai/v1/chat/completions`
