# 2026-03-29 - Daily Log

## OAuth Callback Fix

**Problem:** Google OAuth callback was showing the callback URL instead of redirecting to the app. The callback URL (`https://lipaira.ai/api/auth/google/callback`) was hitting the frontend (React app), not the API server.

**Root Cause:** 
- The `redirect_uri` in server_full.py pointed to `lipaira.ai`
- But the frontend nginx had no route for `/api/*`, so it served the React app instead of the API
- The OAuth callback requires server-side processing to exchange the auth code for tokens

**Solution:**
1. Updated nginx config to proxy `/api/*` requests to the lipaira-api container
2. Fixed encryption.py import (was using wrong PBKDF2 class)
3. Redirect URI now correctly routes through nginx to the API

**Key Lesson:** When using a frontend + backend architecture with OAuth, the redirect_uri must route to the backend API, not the frontend. The nginx proxy now handles this correctly.
