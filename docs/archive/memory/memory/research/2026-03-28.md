# Morning Research - 2026-03-28

## AI Agents & Automation Trends

- **Agentic AI hits enterprise scale**: Moving from pilots to production, with multi-agent systems (MAS) now dominating—IDC predicts 45% of organizations will orchestrate agents at scale by 2030. 82% of companies see it as a growth driver.
- **Claude Code dominates autonomous programming**: March 2026 survey shows 75% adoption at smaller companies, overtaking Copilot/Cursor. New features include computer use (AI controls Mac desktop), /loop scheduled tasks, voice mode, and remote control.
- **Governance-as-code emerges**: Trust and operational discipline over speed—AI governance evolving from policies to embedded operating models, with security and compliance built into agentic setups.
